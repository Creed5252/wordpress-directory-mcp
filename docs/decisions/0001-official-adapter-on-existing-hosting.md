# 0001: Use the official WordPress MCP Adapter on existing hosting

Date: 2026-11-19

The first plan proposed a separate server on a serverless platform. That conflicted with a standing rule for these sites and added an account and a cost. WordPress 6.9 put the Abilities API in core and WordPress.org ships an official MCP Adapter, so the server runs inside the existing sites at $0, inherits WordPress updates, and needs no DNS change.
